# BrandTweet AI

BrandTweet AI is a React-based web application that generates tweet ideas for brands based on their industry, campaign objective, and product details.

## Features

- Generate 10 tweet ideas for a brand.
- Display a brand voice summary.
- Copy individual tweets.
- Copy all generated tweets.

## Technologies Used

- React
- Vite
- JavaScript
- CSS
- Java Spring Boot backend

## Running the Frontend Locally

1. Install Node.js.
2. Open the frontend folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.

## Project Purpose

The goal of BrandTweet AI is to help brands create engaging social media content more efficiently.
